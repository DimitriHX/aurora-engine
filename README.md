# Proyecto-Aurora
Este es un proyecto basado en experiencias personales con el fin de fomentar la experimentacion de construir un sistema con ingenieria simple y dejando de lado la complicidad a largo plazo.
El repositorio tiene como nombre clave Project Aurora donde es un RPG 2D inspirado en la filosofía técnica de los juegos clásicos de exploración y aventura de la era de consolas basadas en Arquitecturas ARM de la epoca de entre los años 2001 a 2010.
El objetivo principal del proyecto NO es recrear un juego existente, sino estudiar y construir una arquitectura moderna, eficiente y escalable para videojuegos 2D utilizando C# y .NET.

---

# Objetivos

- Construir un motor 2D modular
- Mantener bajo consumo de recursos
- Priorizar simplicidad y mantenibilidad
- Crear una arquitectura desacoplada
- Aprender ingeniería de videojuegos real
- Diseñar herramientas reutilizables
- Permitir escalabilidad futura

---

# Filosofía del Proyecto

El proyecto está basado en varios principios:

- Simplicidad sobre complejidad
- Sistemas reutilizables sobre contenido masivo
- Arquitectura limpia sobre velocidad de desarrollo
- Optimización inteligente sobre desperdicio de recursos
- Desarrollo incremental y modular
